01 — Overview

What is a Vector Transformer?

The Transformer is a neural network architecture introduced in the landmark 2017 paper "Attention Is All You Need" by Vaswani et al. at Google Brain. Unlike recurrent networks (RNNs/LSTMs), Transformers process sequences entirely through attention mechanisms — dispensing with recurrence entirely.

At its core, every token in a sequence is represented as a vector in a high-dimensional embedding space. The model learns to relate these vectors to each other through self-attention, allowing it to capture dependencies regardless of how far apart tokens are in the sequence.

03 — Core Concepts

Key Building Blocks

Self-Attention

Each token attends to all other tokens in the sequence, computing a weighted sum of value vectors. This allows the model to dynamically focus on the most relevant context.

Attention(Q, K, V) = softmax(QKT / √dk) · V

Multi-Head Attention

Rather than a single attention function, the model runs h parallel attention heads, each projecting to a different subspace. Outputs are concatenated and projected.

MultiHead(Q,K,V) = Concat(head1..headh) WO

Positional Encoding

Since Transformers have no notion of order, position information is injected as sinusoidal vectors added to the token embeddings before the first layer.

PE(pos,2i) = sin(pos / 100002i/d)

Feed-Forward Layers

After each attention block, a two-layer fully-connected network is applied independently to each position, introducing nonlinearity and expanding representational capacity.

FFN(x) = max(0, xW1 + b1)W2 + b2

Layer Normalization

Applied after each sub-layer (attention and FFN), LayerNorm stabilizes training by normalizing across the feature dimension, combined with residual connections.

LayerNorm(x + Sublayer(x))

Token Embeddings

Words are mapped to dense vectors in R^d space. These embeddings are learned jointly with the model and shared with the output projection layer to reduce parameters.

x = Embedding(token) · √dmodel

07 — Implementation

Scaled Dot-Product Attention in PyTorch

The core of every Transformer — in under 15 lines.

Python · PyTorch 
import torch
import torch.nn.functional as F
import math

def scaled_dot_product_attention(query, key, value, mask=None):
    """
    Compute attention(Q, K, V) = softmax(QK^T / sqrt(d_k)) * V
    query, key, value: (batch, heads, seq_len, d_k)
    """
    d_k = query.size(-1)

    # Dot product of queries and keys, scaled by sqrt(d_k)
    scores = torch.matmul(query, key.transpose(-2, -1)) / math.sqrt(d_k)

    # Apply optional mask (for causal / padding)
    if mask is not None:
        scores = scores.masked_fill(mask == 0, -1e9)

    # Softmax over the key dimension → attention weights
    weights = F.softmax(scores, dim=-1)

    # Weighted sum of values
    return torch.matmul(weights, value), weights
